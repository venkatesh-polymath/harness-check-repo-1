## Idea
Unimodal Gaussian Routing Prior in StaR-MoE Fails for Multi-Modal Class Distributions: A Hidden Alignment Failure in MoE Continual Learning

## Prediction (registered before running)
Superclasses with high intra-class visual diversity (measured by within-superclass feature variance in a pretrained ResNet embedding space) will show significantly higher KL divergence between the true router-input distribution and the fitted Gaussian (D_KL > 0.5 nats), and this divergence will correlate (Spearman r > 0.6) with per-superclass forgetting error relative to an exemplar-storing oracle — while the alignment loss magnitude will NOT correlate with routing drift, revealing it is calibrated to a metric that does not capture multi-modality. Initial evidence: CIFAR-100 superclasses span 5 fine-grained classes with independently learned feature clusters; a single Gaussian covering 'beaver' and 'dolphin' simultaneously inflates variance so much it provides a near-uniform routing prior, defeating the purpose of the alignment constraint.

## Study spec
