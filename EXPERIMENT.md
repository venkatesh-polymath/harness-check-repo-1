## Idea
Linear Attention in TITN's Inner Block: Does Local-Feature Efficiency Sacrifice Structural Expressivity?

## Prediction (registered before running)
Cosine/ReLU linear attention in the inner block will cut FLOPs by 12–18% with <0.5pp accuracy drop on CIFAR-10, but a larger drop (~1.5–2pp) on CIFAR-100, because CIFAR-100's fine-grained classes rely more on precise local spatial relationships. Supporting evidence: inner-block attention matrices in TNT are highly localized and low-entropy — many pairs are near-zero, indicating full O(n²) attention is wasteful; however, the non-zero pairs encode structural geometry that a rank-1 kernel approximation may blur.

## Hypothesis chain (sanity gates FIRST)
  1. Setting a fixed random seed (seed=42) produces bit-identical weight initializations and per-batch loss values across two independent process launches of the TNT model on CIFAR-10. → expect: Two sequential training runs with seed=42 report identical cross-entropy loss for the first 5 mini-batches (diff = 0). (pass if max(|loss_run1[i] − loss_run2[i]|) < 1e-6 for i in {0..4})
  2. A randomly initialized TNT model on CIFAR-10 (10 classes) outputs near-uniform logits, so initial cross-entropy ≈ ln(10) ≈ 2.303. → expect: Measured initial loss on a fresh random batch is 2.30 ± 0.10. (pass if |initial_loss − ln(10)| < 0.15)
  3. A majority-class dummy classifier (always predicts class 0) achieves exactly 10% accuracy on the balanced CIFAR-10 test set. → expect: Dummy classifier test accuracy = 10.0%. (pass if dummy_accuracy ∈ [9.0%, 11.0%])
  4. TNT with standard softmax inner attention can overfit a single fixed batch of 32 CIFAR-10 images to near-zero training loss within 300 gradient steps. → expect: Training loss on the fixed overfit batch falls below 0.01 by step 300. (pass if min(train_loss[0..300]) < 0.01 on the fixed overfit batch)
  5. On 32×32 CIFAR with 4×4 outer patches (64 outer tokens) subdivided into 2×2 pixel sub-patches, n_inner = 4 inner tokens per patch and d_inner ≈ 24; the linear-attention FLOP crossover condition n >> d is definitively not satisfied at this scale. → expect: Config enumeration yields n_inner ∈ {4, 16} depending on sub-patch choice; since n_inner ≤ d_inner, softmax is cheaper per inner block than the linear kernel's d² feature-map term. (pass if A written geometry table documents outer_patch_size, sub_patch_size, n_inner, and d_inner; confirms n_inner ≤ d_inner; TNT nomenclature is used (not TITN) throughout all config files.)
  6. A back-of-envelope FLOP breakdown shows the inner block accounts for < 10% of total TNT FLOPs on the CIFAR config, making the originally predicted '12–18% total-model FLOP reduction' arithmetically impossible, and refuting the efficiency framing before any training run. → expect: inner_block_attention_flops / total_flops < 0.10; maximum achievable total-model cut from fully eliminating all inner-block attention is < 10%. (pass if Numeric FLOP table produced; max_possible_total_cut = inner_block_attention_flops / total_flops reported; if < 0.18, the efficiency claim is logged as refuted and the paper framing is updated to expressivity-only before any GPU job is submitted.)
  7. (pass if std(acc_seed1, acc_seed2, acc_seed3) < 1.0pp AND mean_acc > 75%; training config confirmed to contain no distillation loss term.)
  8. Replacing softmax with ReLU-based feature-map linear attention only in the inner block (outer transformer weights reinitialised identically and trained jointly; no distillation) does not change CIFAR-10 accuracy beyond run-to-run noise. → expect: ReLU-inner mean accuracy across 3 seeds is within 0.5pp of the softmax baseline mean. (pass if |mean_relu_inner_acc − mean_softmax_baseline_acc| < 0.5pp at 3 seeds each.)
  9. Replacing softmax with cosine-kernel linear attention in the inner block (same training protocol as step 8, no distillation) yields accuracy statistically indistinguishable from the ReLU variant, indicating kernel choice does not matter at small n_inner. → expect: Cosine-inner mean accuracy across 3 seeds within 0.5pp of ReLU-inner mean.   10. Empirical FLOP and wall-clock measurements via torch.profiler confirm the analytic prediction from step 6: linearising the inner block produces no meaningful FLOP reduction; the paper's framing is formally pivoted from efficiency to expressivity. → expect: Measured total FLOPs for linear-inner-TNT are within ±5% of softmax-inner-TNT; if linear is slower due to d² feature overhead, speedup ratio < 1.0. (pass if measured_total_flops_linear / measured_total_flops_softmax ∈ [0.85, 1.15]; if ratio > 0.95, a 'Pareto-competitive' or efficiency claim is absent from all subsequent write-up sections.)
  11. Extending the softmax baseline and best linear-inner variant to CIFAR-100 (100 fine-grained classes, 3 seeds each) reveals a larger accuracy gap than on CIFAR-10, because fine-grained discrimination depends on precise local structural geometry that linear kernels blur. → expect: (baseline_c100 − linear_c100) − (baseline_c10 − linear_c10) > 0.5pp; CIFAR-100 loses more from linearising the inner block. ## Study spec
- goal: Measure whether replacing softmax with linear attention solely in TNT's inner block (sub-patch tokens, n_inner=4, d_inner=24 on 32×32 CIFAR) degrades top-1 accuracy, and whether any degradation is larger on CIFAR-100 than CIFAR-10 — study is reframed purely around expressivity because at n_inner=4 < d_inner=24 the linear-attention FLOP advantage does not exist (the d² feature-map overhead dominates, so efficiency claims are dropped entirely)
- scientific (measure): ['inner_attention_type ∈ {softmax, Performer-ReLU-kernel}', 'dataset ∈ {CIFAR-10, CIFAR-100}']
- nuisance (tune per arm): ['peak_learning_rate: tuned independently per arm via 5-point log-grid [1e-4, 5e-4, 1e-3, 5e-3, 1e-2] on a held-out 10% validation split', 'weight_decay: tuned independently per arm ∈ {0.01, 0.05, 0.1}', 'lr_warmup_epochs: tuned independently per arm ∈ {5, 10, 20}']
- fixed (hold constant): ["architecture: TNT (Transformer-in-Transformer); 'TITN' label dropped — same codebase, name corrected", 'outer_attention_type: softmax, held identical across all arms; outer-block weights re-used from the baseline checkpoint so only the inner block varies', 'patch_size: 8×8 px → 16 outer tokens on 32×32 CIFAR', 'sub_patch_size: 4×4 px → n_inner=4 sub-patch tokens per patch, inner_dim=24 (caveat documented in methods: n_inner=4 < d_inner=24, linear attention has no FLOP advantage at this geometry; a back-of-envelope FLOP breakdown — inner-block share of total TNT FLOPs and softmax-vs-linear crossover at (n=4, d=24) — must be computed and logged before any training run starts)', 'distillation: none — teacher dropped entirely to prevent it absorbing inner-block capacity loss and confounding the ablation', 'optimizer: AdamW', 'batch_size: 128', 'max_epochs: 200 with cosine-annealing decay to 0', 'data_augmentation: random 32×32 crop with 4 px padding + random horizontal flip + per-channel mean/std normalization', 'random_seeds: {0, 1, 2} — every arm × dataset combination runs all three seeds', 'image_size: 32×32 px, no resize']
